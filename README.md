# Secure Web Application using Flask

## Objective
Developed a secure authentication system using Flask.

## Features
- User Registration
- Secure Login
- Password Hashing
- SQL Injection Prevention
- Session Management

## Technologies Used
- Python
- Flask
- SQLite
- HTML/CSS
- Werkzeug Security

## Security Features
- Hashed Passwords
- Prepared SQL Statements
- Secure Authentication

## How to Run

Install dependencies:

pip install flask werkzeug

Run application:

python app.py

Open browser:

http://127.0.0.1:5000
